GitHub Pages 部署

1. 在 GitHub 新建一个 Public repository。
2. 上传本文件所在目录中的全部内容，确保 index.html 位于仓库根目录，assets 文件夹也在根目录。
3. 打开仓库 Settings > Pages。
4. 在 Build and deployment 中选择 Deploy from a branch，分支选 main，目录选 /(root)，保存。
5. 等待 GitHub Pages 发布完成，在 Pages 设置页打开生成的网址。

页面包含邮箱和电话。Public repository 与已发布网页都可被公开访问；上传前请确认愿意公开这些联系方式。
